# Linked Lists

*-Linked lists can be persived as a series of nodes 

*-Each node has atleast a sigle poiunter

*-the last node has a null pointer

*-In Data structures and algorithms we always maintain head and tail pointers so that insersition at either the head or the tail of the list is a constant time operation

*-Linked lists have these charecteristics
* 1. Insertion is O(1)
* 2. Deletion is O(n)
* 3. Searching is O(n)

* One thing that stands out on these operations is the insertion operation mainly because if you do an isertion on either the head or the tail of the list the operation in O(1) and when you do an insertion that is not either the head or the tail the complexity is O(n).
